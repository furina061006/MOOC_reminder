- **报告问题 / 提建议**：[新建 Issue](https://github.com/furina061006/MOOC_reminder/issues/new/choose)（有模板，会引导你附上必要信息）
- **改代码**：先读 [CONTRIBUTING.md](../CONTRIBUTING.md)（本地加载扩展、`npm run validate`、以及**不要把抓取产物提交上来**这条红线）
- **了解项目现状**：`AGENTS.md`（索引 + 红线 + 路由表）与 `.dsh/agents/`（分主题的架构、平台、不变量文档）
