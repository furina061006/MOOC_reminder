# 常见问题

> ← 返回 [README](../README.md) ｜ 开发者视角的排查流程见 `.dsh/agents/troubleshooting.md`

## 一件都抓不到 / 列表是空的

按顺序做这三步，能解决绝大多数情况：

1. **确认已登录**中国大学MOOC（浏览器里打开 `icourse163.org` 是登录状态）。
2. 到 `chrome://extensions/` 找到 MOOC Reminder，点一下「**重新加载**」；
   然后**把已经打开的 icourse163 页面刷新一遍**（或重新打开）。
   > 只重载扩展、不刷新页面的话，页面里就没有插件的代码，什么都不会工作——这是最常见的原因。
3. 打开一次「**我的课程**」页（`icourse163.org` 登录后的课程列表），或任意一门课的学习页，让插件认识你的课程。

还是不行？[新建 Issue](https://github.com/furina061006/MOOC_reminder/issues/new?template=bug_report.yml)，
模板会让你附上插件版本、浏览器版本和日志；照着填通常一轮就能定位。

## 只有某一门课抓不到，其他课都正常

这门课的学习页多半**长期挂在后台，被浏览器冻结/卸载了**（Chrome 的省内存机制）。

- 把那门课的页面切到前台一次（它会自动重新加载），再点 popup 的刷新按钮；
- 或者打开一次「我的课程」页，让插件重新登记课程。

## 作业我明明做完了，插件还显示未完成

- 先点 popup 的刷新按钮，让插件重新拉一次数据（打开课程页也会自动刷新，但 30 分钟内不重复）。
- **互评中**的作业会标「手动确认」：平台不公开「你有没有完成互评」，所以需要你自己勾选。
- **考试**同样标「手动确认」：成绩没公布时插件不敢替你判定已完成。

## 没有收到截止提醒

按可能性从高到低检查：

1. 系统/浏览器的通知设置（Windows 通知中心是否允许 Chrome 发通知）；
2. 设置页的「提醒阈值」是不是关掉了某些档位；
3. 设置页的「免打扰时段」是否覆盖了当前时间；
4. 这门课是不是被**静音**了（静音只影响提醒与徽章，不影响抓取）；
5. 设置页「系统反馈」会显示通知权限、可提醒数量和下次检查时间——那里能直接看出问题在哪。

## 怎么更新插件

本插件没上架 Chrome 网上应用店，**Chrome 不会自动更新它**。

1. 打开 [Releases 页面](https://github.com/furina061006/MOOC_reminder/releases/latest)，下载新版 `mooc-reminder-v*.zip` 并解压；
2. 到 `chrome://extensions/`，给 MOOC Reminder 点「重新加载」（或删掉重新「加载已解压的扩展」，选新解压出来的 `MOOC_reminder` 文件夹）。

作业数据不会丢。插件本身会在后台检查新版本（默认每 12 小时一次），发现新版本时弹通知；
不想让它联网的话，在设置页关掉「自动检查更新」即可。

## 换电脑、换浏览器、手机能用吗

- **不跨设备同步**：数据存在当前浏览器的 `chrome.storage.local` 里，换设备需要重新安装；
  装好后打开一次课程页，作业会重新抓回来（历史勾选状态不会跟过去）。
- **手机不行**：这是桌面 Chromium 扩展。

## 数据存在哪里？卸载会怎样？

只存在你自己的浏览器里（不上传任何服务器）。卸载扩展或在 popup 底部点「重置数据」就会清掉。
详见[隐私说明](privacy.md)。

## 支持哪些浏览器？

Chrome、Edge、夸克等 **Chromium 内核**浏览器。Firefox 不支持（用的是 Manifest V3 + `chrome.*` API）。

## 为什么插件要「读取浏览数据 / Cookie」这些权限？

因为抓取要靠你自己浏览器里的登录态（`NTESSTUDYSI` 是 HttpOnly Cookie，网页自己也用它做 CSRF 校验），
而这些请求与你在网页上点开作业时发出的请求没有任何区别。
逐条权限解释见[隐私说明](privacy.md#它要了哪些权限，各自干什么)。
