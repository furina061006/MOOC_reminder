# 2026-11-03 — 发布 1.2.2（新版学习页考试修复）

## 发了什么

1.2.2 只有**一条用户可感知的修复**：新版普通课程（`/mooc/learn/…`）的「期末考试」抓不到（issue #15）。
根因、实现与离线验证见开发日志
[`2026-11-03-new-learn-exams.md`](2026-11-03-new-learn-exams.md)；用户可见说明见
[`changelog.md`](changelog.md) 的 `## 1.2.2（2026-11-03）`。

代码面：

1. 新版学习页是 Next.js 服务端渲染，考试完整数据在 `self.__next_f.push` 的
   `outline.exams[]`，章节树里的 `legacy-exam` 只是不带 deadline 的占位节点；
2. `main.js` 转发内联 Flight 脚本文本；当前页（如 `/content`）没有考试数据时，
   同源请求一次 `/exams` HTML，不导航用户标签页；
3. SW 新增 `PAGE_RSC_DATA`，按 `courseId` + `termId` 匹配 `outline`，只把 `exams`
   交给原有的 `COURSE_API_DATA` / reconcile；
4. 提取器识别 `taskType` / `nodeType` / 有效 `examId` 显式考试，支持
   `parts[].deadline` 与 `parts[].usedTryCount`；shared 与 SW 内联两份副本同步改。
