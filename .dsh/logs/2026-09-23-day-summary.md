## B. 「popup 启动慢」：量了，结论是**不改**

加了临时计时埋点（popup 侧 + SW 侧），用户在自己机器上跑了四次：

| 采样 | 6 次 storage 读合计 | `bootAge` |
| --- | --- | --- |
| 1 / 2 | 5 ms / 38 ms | 16.9 s / 19.1 s |
| 3 / 4 | 14 ms / 28 ms | **854 s / 869 s（≈14 分钟）** |

两个结论：**SW 侧被证伪**（15 条作业、6 次串行 `storage.local.get` 合计 5–38 ms，抖动与数据量无关，
不值得为「慢」去合它）；**`bootAge` 14 分钟是测量偏差** —— MV3 的 SW 空闲 30 秒就挂起，
只有「开发者工具开着时永不挂起」能解释 854 秒。也就是说**为了看日志而打开的 SW 检查视图，
恰好消掉了要观察的冷启动**；四次采样全是热路径。

用户随后自述「感觉变快了」，与热路径一致（SW 被钉住 + 数据已回来不再走空数据那段 ~50s 循环 + 连续打开）。
**决定：不为性能改代码**，埋点按用户要求整块删除，`src/` 与 HEAD 逐字节一致。
唯一仍然值得做、但属于**健壮性**的只有一条：空数据时 popup 自己连发抓取并睡眠轮询最坏 ~50s。

**「怎么测冷启动」已写进 `scheduling.md`**，避免下次再踩：关掉 SW 检查视图 → 静置 ≥1 分钟 →
从 popup 侧量第一条 `sendMessage`（`GET_POPUP_STATE`）——`validateAndAutoRepair` 直读 storage、不唤醒 SW，
所以冷启动只能落在第一条消息上。

## D. 幽灵课程：`NEU-1474956162 · 普通 · 牛顿第二定律`

用户报设置页出现没选过的课。**我先猜了两次，都错了**：

1. 猜「`main.js` 的 `readCourseName()` 抓到了章节名」——错；
2. 猜「SPOC 页上的源课程/章节链接」——也错（为此做的「学习页不采集」是对的，但不是这次的解）。

真正定案靠用户回传的**真实 DOM**（`/home.htm#/home/spocCourse` 另存为 `element.txt`）：
页面里通过 `?tid=` 检查的锚点只有 5 个，全是**首页右侧「最近发表」的论坛帖链接**：

```html
<a href="https://www.icourse163.org/learn/NEU-1474956162?tid=1476735472#/learn/forumdetail?pid=1353455440">
  <span class="f-thide c-ro-posts_span49">牛顿第二定律</span>
</a>
```

锚点文本就是**帖子标题**；采集按 `courseId|termId` 去重，5 条帖子合并成一条、名字取了 DOM 第一条；
该 tid 是 SPOC 的**路由壳**（空壳）所以 0 条作业，href 不含 `/spoc/` 所以类型成了「普通」——
三个疑点全部对上。

修复三层：① `parseLearnHref` 拒绝**内容详情链接**（fragment 含 `forum` / `detail`），两份拷贝同步；
② 学习页不再采集、也不应答探测（顺带修掉它同步应答**抢走 `main.js` 的 `sendResponse`**）；
③ `COURSE_LINKS` 弱信号不改名 + 空名字不写。三条守卫都做了**负向验证**。

## 走过的弯路与教训

1. **「别猜」不是口号**：这次我先猜了两个方向（`readCourseName`、源课程链接），各自还顺手做了修复；
   真凶（论坛帖链接）是**用户回传真实 DOM**之后一次定案的。以后这类问题第一步就是**要 DOM/DTO 证据**，
   而不是从代码里反推可能的成因。
2. **观察者效应**：为了观察 SW 冷启动而打开 SW 的 DevTools，恰好让 SW 永不挂起 —— 四次采样全是热路径。
   测性能前先问「我的观测手段会不会改变被测对象」。
3. **「本地包 = CI 附件」该验的是内容不是哈希**：两边都是 625924 字节，但 **sha256 不同**（zip 写入文件
   mtime，CI 的时间戳来自 checkout）。`operations.md` 里原先写的「逐字节同源」是错的，已更正为
   「内容完全一致」，并注明正确姿势：**先比大小，再解压 `diff -r`**；别拿 sha256 / GitHub 的 `digest` 对比。
4. **索引文件不是手册**：`AGENTS.md` 每轮都在上下文里，写法技巧、调试技巧这类内容应进
   `.dsh/agents/<主题>.md`，索引里只留一行路由。
